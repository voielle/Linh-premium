# Linh Premium™ — Coding Source of Truth

This file records the locked product decisions used for V1.

## Visual

- Coffee Date by Clique83-inspired minimal editorial aesthetic.
- Palette: Black / Ivory / Burgundy.
- Main text centered.
- Mobile-first and responsive.
- Portrait/landscape do not change the layout.
- DM Serif Display for display/question text.
- Manrope for body/UI.

## Core interaction

- No question numbers.
- No progress bar.
- No running Hearts total.
- Answer locks immediately.
- Answer cannot be changed.
- Fixed Hearts appear beside selected answer.
- AI-scored free-text answers show `+? ❤️`, not the hidden score.
- Feedback is italic.
- Auto-transition after approximately 3 seconds.

## Flow

Landing → Trial end OR Start Upgrade Process → Q1–Q10 → final score → final result → Confirm Upgrade → Premium activated → 7 benefits → final punchline.

## Final result

Only:
`You earned XX ❤️`

Then direct personalized feedback, no heading.

Critical feedback patterns have priority over score ranges:
1. Strong relationship alignment.
2. Affectionate but independent.
3. Good score, unclear intention.
4. Relationship mismatch.
